# 누스냥 편집 규칙 (Claude Code 작업 지시서)

이 파일은 누스냥 유튜브 영상 4개(Higgsfield + Gemini 분석)를 바탕으로 만든 편집 규칙이다.
원본 방송 녹화본을 받아 아래 규칙대로 **1차 편집본(mp4) + 자막(SRT) + 편집 지점 목록**을 만든다.
최종 꾸미기(자막 템플릿, 말풍선, 밈 짤, 효과음 미세 조정)는 사람이 CapCut에서 한다.

## 0. 작업 환경
- 도구: ffmpeg(+ffprobe), 음성 인식은 faster-whisper 등(한국어). 없으면 설치부터.
- 원본은 절대 수정·삭제하지 않는다. 결과물은 `output/` 폴더에 저장.
- 원본이 길면 먼저 저해상도 프록시를 만들어 분석하고, 최종 렌더만 원본으로 한다.

## 1. 전체 구성
1. **오프닝 후킹 (0:00~0:10~15)**: 본편에서 가장 극적인 장면(절규, 멘붕, 대성공) 하나를 맨 앞에 배치.
2. **채널 인트로 (~10초)**: 고정 인트로 영상이 있으면 삽입. 영상 종류에 따라 인트로 없이 "오늘의 컨텐츠" 타이틀 자막으로 바로 시작하기도 함 → 사람에게 확인.
3. **본편**: 문제/목표 제시 → 시도와 실패 반복 → 감정 폭발 → 해결·반전 → 보상(강화 성공, 클리어 등).
4. **엔딩**: 짧은 인사 → 분홍 톤 시그니처 아웃트로 카드 약 20초.
- 완성 길이: 보통 10~18분.

## 2. 컷 편집
- 침묵·공백은 거의 100% 제거(점프컷). 대화 구간 컷 길이 1~3초.
- 반복 작업(강화, 큐브, 보스 트라이)은 결과 위주로 압축하거나 배속.
- 실패 장면은 연속으로 이어 붙여 "고난"을 압축해서 보여줌.
- 남길 것: 리액션, 핵심 멘트, 재미있는 채팅/TTS 후원, 결과 화면.

## 3. 자막
- 대사 자막: 하단 중앙, 흰 글씨 + 검정 테두리, 둥글고 굵은 폰트(메이플스토리체 계열).
- 강조 자막: 노랑/하늘/핑크/빨강, 크기 키움. 비명 때는 흔들림.
- 속마음/상황 자막: 얼굴 근처, 괄호() 활용, 3인칭 관찰자 드립 (예: "사이버 진상 손님 등장", "킹모장 ON", "멘헤라 경보 발령").
- 시청자 채팅: 초록/하늘색 말풍선 박스로 화면에 박제.
- 드립 자막은 3분당 1개 이상 **제안 목록**으로 따로 정리(최종 결정은 사람).
- 수치(환산 %, 스타포스 성수, 메소)는 자막으로 명확히 표시.

## 4. 화면 효과
- 리액션(당황, 분노, 환호) 때 캠 얼굴 단계별 줌인.
- 비명·분노 때 화면 흔들기.
- 대실패·충격 때 흑백 또는 정지 + 큰 텍스트.
- 중요한 게임 수치·아이템 옵션은 줌인/클로즈업.
- 날짜가 바뀌면 '벨기에 시간' + 날짜 전환 자막.

## 5. 효과음·BGM
- 자막 팝업: '톡/뿅/피용' 가벼운 소리. 성공: '짜잔/띠링'. 당황/실패: '띠용/두둥'.
- BGM: 평소 경쾌한 캐주얼 곡, 멘트 구간은 10~20% 볼륨. 위기 땐 슬픈 곡, 강화·클리어 직전엔 긴장감 곡, 반전 땐 음악을 뚝 끊음.
- 음원 파일은 사람이 제공한 것만 사용(저작권).

## 6. 반드시 지킬 것
- **개인정보(본인인증, 카드·전화번호, 주소 등)가 보이는 구간은 가림**(원본처럼 풍경 이미지로 덮거나 블러). 의심되면 목록에 표시하고 사람에게 확인.
- 확실하지 않은 판단은 추측하지 말고 "확인 필요" 목록으로 넘긴다.

## 7. 결과물
- `output/rough_cut.mp4` (1080p, 원본 프레임레이트)
- `output/subtitles.srt` (대사 자막)
- `output/edit_notes.md`: 사용한 구간 타임코드(원본 기준), 오프닝 후킹 선택 이유, 줌/흔들기/흑백 위치, 효과음·BGM 넣을 위치, 드립 자막 제안, 개인정보 확인 필요 구간
